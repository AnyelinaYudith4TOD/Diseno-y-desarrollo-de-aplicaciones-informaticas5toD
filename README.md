## 📌 Descripción del programa

LABOLAROSA es un programa de consola desarrollado en C# que permite gestionar los artículos de una tienda de accesorios mediante un menú interactivo.

El programa facilita la administración de productos, permitiendo agregar, buscar, visualizar y gestionar artículos. También incorpora estadísticas para consultar información relacionada con los precios de los productos.

Este proyecto tiene como finalidad poner en práctica los conocimientos adquiridos sobre programación en C#, utilizando listas, métodos, estructuras condicionales y ciclos.

## ✨ Funcionalidades principales

| Funcionalidad | Descripción |
|---|---|
| ➕ Agregar artículos | Permite registrar nuevos productos. |
| 🔎 Buscar artículos | Busca productos dentro de la lista. |
| ✏️ Modificar artículos | Permite actualizar información de los productos. |
| 🗑️ Eliminar artículos | Elimina productos registrados. |
| 📦 Mostrar artículos | Visualiza los productos disponibles. |
| 📊 Estadísticas | Calcula el precio mayor, menor y promedio. |
| 🔃 Ordenar artículos | Organiza los productos de la lista. |
